# Bona Launcher

A small, fast Minecraft launcher made for the BONA friend group.

> **Members only.** Bona Launcher works only for people who have the **BONA** role in the BONA Discord server.
> Ask the developer for details.

## What it does

- **Every loader:** Vanilla, Fabric, NeoForge and Forge, for any Minecraft version.
- **Instances:** one per setup, each with its own memory, Java and settings.
- **Accounts:** offline names and Ely.by (including two-factor).
- **Modpacks:** install `.bonapack` with a double-click, or import Modrinth and CurseForge packs. Export your own.
- **Updates itself:** new versions install with one click.
- **Light on your PC:** about 12 MB, no background services.
- **Crash help:** a plain-words cause and a report you can copy.

## Install

1. Download **Bona-Setup.exe** from the [latest release](../../releases/latest).
2. Run it. Choose where Bona should live (or keep the default) and finish the setup.
3. Open Bona and sign in with Discord once.

Windows may show a "Windows protected your PC" notice because the installer is not code-signed. Click **More info**, then **Run anyway**.

**Requirements:** Windows 10 or 11 (64-bit) and an internet connection the first time (Bona downloads Minecraft and Java for you).

## Updates

Bona checks for updates when it starts. When one is ready, a green button appears above the settings icon. Updates are signed, and Bona refuses anything that is not signed by the developer.

## Privacy

- Bona asks Discord only whether you have the BONA role in the server. It does not read your messages or your other servers.
- Sign-in details are stored encrypted for your Windows user.
- Bona has no analytics and sends nothing about you anywhere else.
